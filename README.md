# PDF-OCA
## v0.7.1 — Agnes AI Provider
Android-first PDF utility application.
- OpenAI-compatible AI provider
- Agnes endpoint: https://apihub.agnes-ai.com/v1
- Default model: agnes-3.0-flash
- Fallback model: agnes-2.5-flash
- GET /models
- POST /chat/completions
- API key stored locally with Android encrypted preferences
- No API secret committed to source
Roadmap: PDF page management, internal page splitting/cropping, OCR/searchable PDF, PDF/image conversion, watermark, encryption/decryption, AI document summarization and Q&A.
